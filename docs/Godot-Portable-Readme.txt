RACE POKER 1.1.0 - WINDOWS x64

Extract the entire ZIP into a folder, then open RacePoker.exe.
Keep the data_RacePoker.Godot_windows_x86_64 folder beside the executable.
Godot and the .NET runtime are included; no editor or SDK is required.
Requires Windows 10/11 x64 with OpenGL 3.3 graphics support.

1-5 or F1-F5: pick a card
Enter: start race / skip the between-round wait
P: pause or resume     S: settings     M: sound
G: payouts            H: history      F11: fullscreen
Esc: close a dialog

Settings and race history save automatically in:
%APPDATA%\Godot\app_userdata\Race Poker • Godot Prototype
